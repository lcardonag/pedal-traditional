# AAMF factory metadata

This directory is written by the Agentic Application Migration Factory during remediation.

| File | Purpose |
|------|---------|
| `remediation-task.json` | Task envelope before Coder runs (factory commits) |
| `remediation-result.json` | Outcome after Coder / Validator |

Branches: `fix/remediation-{id}` → PR to `main`.

Factory orchestration repo: `agentic-application-migration-factory`.
